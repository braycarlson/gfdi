# gfdi

A tool to pull FIT files from a Garmin watch over Bluetooth LE. The usual path for an activity is a sync to Garmin Connect and a download back, so the tool speaks Garmin's GFDI protocol directly and copies the files with no Garmin software involved. The `observe` command reconnects until the archive is complete and remembers what it has saved, so an interrupted pull resumes where it stopped. The Windows backend uses WinRT, and the Linux backend uses BlueZ. Each backend is one large instance that owns every buffer it uses, so a caller creates it once at startup, initializes it in place, and never moves or copies it before `deinit`, and nothing is allocated afterwards. A fake backend runs the same session against scripted files, so the tests and the example in `examples/observe.zig` run without a watch.
